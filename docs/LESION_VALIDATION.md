# 病灶接口验证范围

本次基于合并后的 0.2.0rc1 结构像主线接入独立病灶命令。现有 T1/T2 命令、冻结引擎、参数、审批与结果不改；不恢复已移出的 BOLD/GLM/CFM，也不重复新增 T2 配准。模型源码、权重、许可证、患者数据与本机配置不随 PR 提交。

2026-11-05：现有结构像测试 38 passed（含 SimpleITK 2.5.6）；T2 冻结引擎校验通过，wheel 的 21 个模块与打包清单完全一致。已从仓库外调用安装后的新旧 CLI，并核对结构入口保持原样。使用显式毫米单位的合成 T1/背景/掩膜检查准备、导入、未审核拒绝导出、明确审核、导出内容一致性和非法 dry-run 无写入。开发检查脚本和合成结果留在仓库外，不随包提交；保留上游原有测试。

Slicer 桥接保持本地已验证的保存/恢复实现，文档截图仅含合成影像。先前合成 GUI 验证及随机微型模型推理只证明接口行为，不证明训练权重的准确率。本次结构主线适配不宣称重新完成患者、GPU 或真实容器端到端验收。

既有准备记录只对明确列出的先前引擎哈希兼容；仍要求当前输入毫米单位、物理网格与冻结文件哈希通过。旧审核不自动转移到新输入、新掩膜或新病例。

新命令是研究预览。病灶审核仍需用户全体积检查，不能把导入成功、模型 softmax 分数或界面保存当作临床确认。实际个体配准、背景对应及病灶边界继续按原结构流程核查。
