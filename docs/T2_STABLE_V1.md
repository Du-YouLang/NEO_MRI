# T2结构流程 v1：已审核基线

2026-11-04用户认可本轮T2脑域与配准结果，要求凝固相关代码。T2_structural_v1固定本轮验证过的计算引擎，不修改既有输出、指纹或回执。它是当前研究项目的稳定基线，不代表所有医院序列的临床验证。

## 固定的内容

- 同访视三维T2w与已经审核的患者T1、对应MNI变换；原始输入只读。
- 四线程，SimpleITK 2.5.6，Mattes互信息六自由度刚性，多尺度和固定采样种子，沿用原引擎参数。
- N4估计区仅允许排除不超过1%的零值；出现负值、有效体素不足或零值超限时停止，不给原图加常数。初始刚性、源网格脑域和零值审计先保存。
- 原始强度与N4两条路线均保留。按用户后续指定，脑域默认`brain_domain: hd_bet`，必须提供独立HD-BET的`source_mask`；主结果为raw_independent_HDBET和n4_independent_HDBET，原引擎同时保留T1脑域对照。所有配准仍使用批准T1固定脑域，HD-BET额外约束移动像脑域，并非放弃T1参考。
- T1脑域仅作显式可选：设置`brain_domain: t1_domain`，只计算raw_T1_only和n4_T1_only；即使提供source_mask也不使用它。缺少HD-BET掩膜时默认路径停止，不自动切换或启动外部模型。此选择来自用户指定，不宣称是数值排名的唯一赢家。
- 保存刚性与组合pull；强度线性、标签最近邻。单次组合重采样用于避免重复插值，仍保留同变换的两次重采样结果供审阅。
- 不重新拟合T1→MNI，不重算BOLD/GLM，不增加去噪、锐化、最终图像平滑或直方图匹配。配准内部金字塔的尺度平滑仍保留。
- 输入、审批、正逆变换、实际代码/参数/软件版本及全部输出内容核验；不以文件存在就认定完成。不覆盖失败目录，不自动重试科学计算。

## 怎么调用

在独立项目目录安装核心及可选依赖`pip install '.[anatomy]'`。HD-BET环境继续独立管理，不合并到核心依赖锁。

```powershell
neo-mri-t2-v1 policy
neo-mri-t2-v1 plan --config T2.local.json
neo-mri-t2-v1 run --config T2.local.json
```

plan只校验，不启动计算；run还需要execution_enabled=true，并由本地调度限制时间、资源和共享锁。配置字段和pull方向见[T2/FLAIR说明](T2_FLAIR_EXPERIMENT.md)。示例见[配置](../configs/examples/t2_v1.example.json)，所有路径都需要替换为实际影像及审核记录。

v1入口核验固化引擎的UTF-8/LF内容哈希，源码变化会停止，须另建版本重新验证。原`neo-mri-structural`仍作为对照研究入口，旧结果缓存身份不变。v1本身不启动WSL/Docker，不安装模型，不转移任何旧患者批准给新输入。
