# T2/FLAIR独立预处理与验收

2026-11-04更新：T2部分已获用户视觉审核批准，并以不改变本轮引擎的方式凝固为[T2_structural_v1](T2_STABLE_V1.md)。下文保留对照研究的设计和历史记录；`neo-mri-structural`仍是原实验入口，稳定版本使用`neo-mri-t2-v1`。FLAIR与新个体的审核不从这次T2批准自动推导。

当前为实验入口，不把三例样本通过当作所有医院输入生产验收。旧病例脚本仅供历史追溯；不要重新运行其“文件存在即跳过”路径生成新的正式结果。

## 已实现的选择与依赖

`neo-mri-structural plan/run --config local.json`使用可选依赖`SimpleITK==2.5.6`，核心统计环境不用强行合并HD-BET依赖。安装`.[anatomy]`；HD-BET仍由独立环境执行。plan不启动WSL/Docker或拟合；run需要execution_enabled=true，不自行启动服务，外层调度负责锁、内存和30分钟时限。

配置指定source、modality（T2w/FLAIR）、t1、mni、anatomy_review、normalization_provenance、mni_review、mni_to_t1_pull、output，可选source_mask和lesion。病灶分支还需t1_to_mni_pull。两个pull是已有ANTs image-mode正/逆H5：前者从输出MNI物理点取样到T1，后者从T1取样到MNI；不能照文件名把其当作点推送方向。MNI用户决定采用显式审批记录，其branches中的normalization_provenance SHA须与本次一致。原生脑掩膜审批仍核验原图、mask与比较清单SHA。

source必须为明确的三维标量影像，拒绝直接把Dixon多成分或多回波四维文件当BOLD时间序列；拒绝相互冲突的qform/sform。原始文件只读。配准参考始终为已审核T1；不重新拟合其MNI变换。

## 对照如何隔离因素

先以原始结构像得到共同的刚性初始对应，把批准T1脑域映回源网格，作为N4估计区域。N4估计低频偏置场，不改变网格，不默认排除病灶；必须审核病灶对比和偏置场。本轮控制点/迭代属于预实验设置，不能直接宣称适合全部T2/FLAIR。

四支是raw_T1_only、n4_T1_only、raw_independent_HDBET、n4_independent_HDBET。所有分支均使用固定T1脑域；只有后两支额外使用独立HD-BET移动像掩膜约束代价函数。HD-BET在原始T2/FLAIR上生成一次，raw/N4之间固定，不混入重提取差异。T1_only并非毫无脑域约束，也不是将全头颅骨用于同等权重拟合。掩膜用于代价函数，不将硬裁脑边界当成组织信号。

配准是SimpleITK Mattes互信息六自由度刚性，多尺度、固定采样种子、每工具4线程。这是新实验分支，不宣称与旧FLIRT命令逐位相同。内部配准金字塔使用尺度平滑；最终图像没有额外去噪、锐化、平滑或直方图匹配。不默认放开仿射或非线性自由度。

每支保存刚性pull与组合pull。组合顺序由物理坐标合成测试验证并展平嵌套结构后保存H5；强度使用线性、标签使用最近邻。单次/两次结果使用同一组变换，禁止重拟合后将差异都归于插值。小病灶体积仍在原发布者分割网格计算；MNI标签另行描述。

## 防止误复用与误通过

请求指纹绑定源图、T1/MNI、正逆变换、脑掩膜审批、MNI审批、可选病灶/独立mask、核心代码、固定参数和实际软件版本。仅目录或文件名相同不能复用；所有完成输出重新校验SHA。未完成、失败、指纹改变或输出被改写时停止，使用新版本，不能覆盖或自动重试。运行结束再次核对输入内容。

结果始终COMPUTED_REVIEW_PENDING。脑域Dice、病灶往返Dice和插值RMSE均不能自动批准解剖质量或临床有效性。互信息在改变掩膜/强度后不直接按数值排名。没有独立解剖标记点时不报告定位准确率。
